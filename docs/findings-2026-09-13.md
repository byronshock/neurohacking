# What the sweeps of September 12 and 13, 2026 found

Every run below is `sustain_inputs` or `improved_sustain` on the array
engine, a million epochs an arm unless stated, scored on the input neurons
read back at the end of a 20 ms epoch. The raw runs are under `runs/`
(gitignored); each sweep's own table and figures are the other files in
this directory.

## The read never leaves chance

Across roughly 400 arms the score sits at 0.500. These are the axes that
were varied, each over the range given, with the score unmoved:

| knob | range swept |
|---|---|
| release gamma alpha | 0.5 to 20 |
| release gamma theta | 0.25 to 100 ms |
| pool decay (DOPAMINE_TAU) | 20 ms |
| expectation window | 1 to 10 min |
| expectation start | 0, 0.2, 20 |
| learning rate | 0.0001 to 0.1 |
| punishment gain | 1 to 15 |
| weight decay | 0 to 0.01 per epoch |
| leak (TAU) | 2 to 12 ms, and off |
| refractory hops | 1.01 to 7.9 |
| threshold | 0.125 to 2 |
| topology | 8x10 and 4x10 reach 2, 10x7 reach 3 |
| the rule | dopamine, teacher, reinforce |
| the read | fired this epoch, a window, spiked again |
| the critic | row, sustained |

## Why, in one sentence per finding

**The mesh has two states, not a spectrum.** Under the dopamine rule it
either reverberates at a pool of 1 to 200 units, which pays itself and
runs away, or it is dead at 0.023, the trickle the forced neurons alone
release. Decay and gain trade one for the other; no setting holds it
between. (`docs/decay_seeds.md`, `docs/hops_gain_decay.md`.)

**A collapse is the expectation overtaking the pool.** In every arm that
burned and died, the moment of death is the crossing, within a minute.
From a high start (20) nothing ignites and the same crossing happens from
above. The starting value moves when the crossing comes and nothing else.
(`docs/expect20_seeds.md`, `docs/expect0.2_seeds.md`.)

**Punishment reaches the weights but not the read.** Reversing a bit-0
input neuron's update stops its incoming weights climbing (mean shift
+0.03 against +0.23) and changes no epoch's score, because the mesh's
reverberation drives every input neuron whatever its bit.

**The forced spike is a liability under the old read.** At the punished
equilibrium a neuron that was forced is refractory when the mesh's kick
arrives, so it reads off, while an unforced one takes the kick and reads
on: P(on | bit 1) around 0.01 against P(on | bit 0) around 0.4, a score
below chance. (`docs/hops_gain_decay.md`.)

**Above a hop ratio of about 5.9 the mesh stops dying.** All 21 arms at
5.95, 6.9 and 7.9 survive a million epochs with the pool at 1.1, the
expectation just above it, and no weight pinned. But the living state is a
20 ms limit cycle: 62 of 70 neurons fire inside the first 2.2 ms and then
everything is refractory together, so nothing refires within its own epoch
and the read is empty. (`docs/improved_hops_fine.md`.)

**The external teacher speaks clearly and is not heard.** Its score is
exactly Byron's: +0.25 a neuron read right, -0.25 a neuron read wrong. Its
mean over a run is within 0.002 of zero, because the mesh's behaviour is
uncorrelated with the pattern, so the eligibility it pays is a random walk.
With weight decay on, the zero-mean signal cannot oppose it and every arm
dies within minutes; with decay off the mesh lives and the weights walk to
the rails in some arms. (`docs/teacher_hops.md`,
`docs/teacher_hops_nodecay.md`.)

**The threshold was already right.** Below 0.5 the mesh saturates, above it
the input cells stop refiring and hundreds of weights are driven to the
floor; 0.25 sits in the only window where the input cells refire with the
weights off the rails. (`docs/teacher_threshold.md`.)

## What this leaves

Nothing a neuron can observe differs between an epoch where it should fire
and one where it should not: the mesh around it does the same thing either
way, and the only pattern-dependent event, its own forced spike, reaches
nothing but itself. Every knob above changes how the substance burns. None
changes that. The next move is in the structure of §4 or §6, not in their
constants.
